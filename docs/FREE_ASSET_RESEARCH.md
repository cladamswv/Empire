# Free Asset Research for Empires Rise

## Strong free sources found online

1. **KayKit: City Builder Bits**
   - Free / CC0
   - 32+ low-poly city models
   - GLTF / FBX / OBJ
   - Good for fast blockout and cozy stylized prototyping

2. **KayKit: Prototype Bits**
   - Free / CC0
   - Useful for quick mockups, props, and placeholder interactions

3. **KayKit: Resource Bits**
   - Free / CC0
   - Useful for wood, stone, ore, and economy-site props

4. **3DAssets.dev – Roman Bathhouse and Palaestra**
   - Free / CC0
   - Strong candidate for Roman/classical props and architecture accents

5. **CC0Tree**
   - Free / CC0
   - Useful for trees and stylized environment dressing

## Prototype direction decision

For this build, the prototype uses **custom in-engine mockup graphics** instead of depending on remote downloads.
This keeps the prototype:

- lightweight
- GitHub-ready
- self-contained
- easy to iterate

Later versions can import free CC0 assets to improve the look while preserving the same city interaction model.
