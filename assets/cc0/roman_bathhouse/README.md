# Optional CC0 Roman accents

Run `tools/fetch_cc0_assets.sh` to place the GLB files here.

Source pack: Roman Bathhouse and Palaestra, 3DAssets.dev
License: CC0 1.0 Universal
https://3dassets.dev/packs/roman-bathhouse-and-palaestra

The game does not require these files. `CityView.gd` falls back to procedural meshes when they are absent.
