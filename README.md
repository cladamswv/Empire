# Empires Rise v0.4 — Stylized Interactive Prototype

This build is a visual reboot of the early prototype. It focuses on making the project feel like a real mobile strategy game before adding deeper systems.

## What's new

- Reframed full-screen city presentation with a cleaner mobile HUD
- Sleek dark/gold strategy-game UI instead of developer-test controls
- Five dedicated resource cards with hourly production
- Compact CITY / WORLD / REPORTS navigation
- Stylized 2.5D city with richer terrain, coast, distant hills, roads, plaza, fountain, walls, aqueduct, trees and citizens
- More distinctive building silhouettes and details
- Animated banners and chimney smoke
- Drag-and-drop buildings, including position swapping when a tile is occupied
- Civilization visual themes for Rome, Egypt, Carthage and Greece
- Reworked world map with rivers, forests, mountains, roads, landmarks and civilization-specific city markers
- Cleaner city/world context panel
- Updated GitHub Android workflow and stricter smoke test
- Android ETC2/ASTC texture-compression setting enabled

## Prototype controls

- **CITY**: inspect the city, click buildings, and drag them between plots
- **WORLD**: select cities and test Scout / Attack report actions
- **REPORTS**: read the prototype chronicle
- Bottom BUILD dock: add structures
- Bottom CITY STYLE dock: switch between Rome, Egypt, Carthage and Greece

This is still a prototype, but the visual target is deliberately stylized/chibi-friendly rather than photorealistic.
